# Change Request Report

## What is a software change request

A software change request is a formal proposal to modify a software system. It specifies a desired change that can take the form of a new feature, a bug fix, or an improvement to existing functionality. A change request documents the purpose of the change, the expected behavior, any constraints, and acceptance criteria used to confirm correct implementation.

## Types of change requests

- New feature: A request to add functionality that does not currently exist.
- Bug fix: A request to correct unintended or erroneous behavior.
- Improvement: A request to enhance performance, usability, maintainability, or other non-functional or functional aspects of the system.

## Why write user stories from the user's perspective

Writing user stories from the perspective of the person who desires the capability centers the requirement on user value and outcomes. This perspective clarifies who benefits, what goal is sought, and why the capability matters, which supports prioritization, acceptance criteria definition, and testable implementations. Framing requirements as user-centric narratives reduces ambiguity, aligns stakeholders on expected value, and guides designers and developers toward solutions that satisfy real user needs.
